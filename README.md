# 🌊 EcoSea - Jogo de Limpeza dos Oceanos

O **EcoSea** é um jogo interativo simples desenvolvido em JavaScript utilizando a biblioteca **p5.js**. O objetivo do jogo é consciencializar os jogadores sobre a poluição marinha, desafiando-os a recolher o lixo espalhado pelo oceano antes que o tempo acabe, enquanto evitam perturbar a vida marinha.

## 🚀 Como Executar o Jogo

Existem duas formas fáceis de correr este projeto:

### Opção 1: No p5.js Web Editor (Mais rápido)
1. Copia todo o código do jogo.
2. Acede ao [p5.js Web Editor](https://editor.p5js.org/).
3. Cola o código no editor central e clica no botão **Play (▶)**.

### Opção 2: Localmente no teu computador
1. Cria uma pasta para o projeto.
2. Cria um ficheiro chamado `index.html` e inclui o script do p5.js:
   ```html
   <!DOCTYPE html>
   <html lang="pt">
   <head>
       <script src="[https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.4.0/p5.js](https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.4.0/p5.js)"></script>
       <meta charset="utf-8" />
   </head>
   <body>
       <script src="sketch.js"></script>
   </body>
   </html>
